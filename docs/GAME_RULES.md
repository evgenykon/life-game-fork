# Game Rules

## Description

Выживание простейших цивилизаций на карте с ресурсами

## Типы клеток (CellType)

- **base** — база расы. На карте от 1 до N штук. При потере последней базы раса погибает.
- **resource** — клетка с ресурсом. Может быть одного из типов (см. таблицу). Можно строить фабрику для добычи.
- **fabric** (состояние клетки) — на клетке работает фабрика. Собирает ресурсы каждый цикл.

## Ход игры

- Каждая раса стартует с 1 клетки базы.
- Стартовый набор ресурсов: meal 200, water 200, material 200.
- Минимальная дистанция между базами: 4 клетки.
- Размер карты: 20×20 (по умолчанию).

### Каждый цикл (1 сек):

1. **Захват** — продолжается текущий захват клетки, если есть.
2. **Атака** — продолжается текущая атака вражеской клетки, если есть.
3. **Фабрики** — все строящиеся фабрики прогрессируют (-1 material/цикл каждая).
4. **Новое действие** — если нет активного захвата или атаки, раса выбирает одно:
   - **Захват** — если есть свободная клетка рядом с территорией. Стоимость захвата — из таблицы.
   - **Атака** — если есть вражеская клетка рядом. Длится 5 циклов, -1 material/цикл. Требуется material >= порога (max 1, round(10 - war * 0.1)).
   - **Стройка фабрики** — если есть своя клетка без фабрики. Выбирается клетка с наибольшим дефицит-весом. Порог: max 1, round(10 - building * 0.1).
5. **Выбор действия** — взвешенный случайный выбор между доступными опциями пропорционально приоритетам (war / expansion / building).
6. **Сбор ресурсов** — со всех клеток с готовой фабрикой. Ресурс на клетке истощается.
7. **Содержание** — списывается meal 2, water 1, material 1.
8. **Дефицит** — при нехватке любого ресурса теряется 1 клетка с края территории (приоритет: истощённая → обычная → фабрика-стройка → фабрика-готовая → база).
9. **Истощение** — ресурс на клетке уменьшается на `max(1, floor(cycle / 10) + 1)` за цикл. При 0 — клетка истощается.
10. **Восстановление** — истощённая клетка восстанавливается через 10 циклов.

### Бой

- **Атака** — занимает 5 циклов, -1 material/цикл. Цель выбирается по приоритету: база > фабрика > ресурсная ценность.
- **Освобождение** — если атакуемая клетка окружена клетками атакующей расы (все соседи по сторонам света), захват происходит за 1 цикл.
- При захвате клетка переходит атакующему, защитник теряет её из контролируемых. Если у защитника не осталось баз — он погибает.

### Приоритеты рас

Каждая раса получает случайные веса (сумма = 100%):
- **expansion** — захват новых клеток (расширение территории)
- **building** — строительство фабрик на захваченной территории, восстановление истощённых клеток
- **war** — атака вражеских клеток для отбора их ресурсов

### Дефицит ресурсов

Приоритеты AI корректируются текущим уровнем ресурсов:
- Расчёт: сколько циклов осталось до истощения каждого ресурса.
- При deficit > 5 (осталось < 5 циклов) — порог стройки принудительно 0 (обязательно строить).
- Выбор клетки для фабрики учитывает дефицит: выше приоритет у клеток, дающих самый дефицитный ресурс.
- Если любой ресурс падает ниже 30% от стартового (< 60 ед.), раса перераспределяет приоритеты (1 раз в 10 циклов): 20 ед. забирается у самого низкого приоритета и добавляется к нужному (expansion при нехватке еды/воды, building при нехватке материала).
- Если на расу напали (кто-то атакует её клетку), приоритет войны немедленно повышается на 20 ед. (за счёт expansion и building по 10) — не чаще 1 раза в 10 циклов.

## Хранение

- localStorage не используется. Каждая игра начинается заново при старте.
- При нажатии «Стоп» в меню — карта сбрасывается, возвращается экран настроек.

## Интерфейс

- **TopBar** — цикл, количество живых рас, ресурсы на карте, зум.
- **Меню (бургер)** — пауза/продолжить, рестарт, стоп.
- **Правая панель** — настройки до старта. После старта скрывается.
- **Шторка расы** — открывается кликом по базе. Графики ресурсов и территории, текущие показатели, стратегия.
- **Модалка баланса** — открывается из правой панели. Редактируемые числовые константы игры.
- **Модалка победы** — графики победителя, доминирующая стратегия.
