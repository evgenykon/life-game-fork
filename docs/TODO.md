## Pending

- [ ] Реализовать игровой движок
    - **Типы данных**: `ResourceType` (9 типов), `CellType` (base, resource, fabric, shadowed), `Cell`, `Race`, `GameState`.
    - **Генерация карты**: 2D массив `width × height`. Каждая клетка с вероятностью `density%` получает случайный ресурс (взвешенный рандом), иначе пустая. Расы размещаются случайно, минимум 5 клеток друг от друга.
    - **Хранение (localStorage)**:
        - Ключ `${hash}-${x}-${y}` → параметры клетки.
        - Ключ `${hash}-meta` → параметры карты, номер цикла, расы.
        - Хэш: 16-символьный рандомный hex, хранится в URL.
        - При загрузке страницы с хэшем → пытаемся загрузить всё из storage. Если ошибка/нет данных → ресетим карту, генерим новый хэш, обновляем URL.
        - При генерации новой карты → чистим все ключи со старым хэшем.
